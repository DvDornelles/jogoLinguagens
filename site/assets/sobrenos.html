A Equipe LAVI

Nós somos estudantes do 2º ano do Ensino Médio Integrado no IFRS - Campus Canoas. Desenvolvemos este Escape Room Virtual como projeto de conclusão para a disciplina de Linguagens para a Internet.

"Sobreviver ao Cubo não é apenas um jogo para testar sua mente, é o código que testou a nossa!"
